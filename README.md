# Automation-Smart-File-Organizer

An interactive Streamlit application for organizing files automatically, categorizing files by type, detecting duplicate files, and exploring file details with an interactive dashboard.

Built with Python, Streamlit, Pandas, and Plotly.

## Features

- Scan files and folders
- Automatically categorize files by type
- View file categories and statistics
- Visualize file distribution with interactive charts
- Search and explore file details
- Detect duplicate files using SHA256 hashing
- Organize files into category folders
- Download file reports

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/snehajoyti/Automation-Smart-File-Organizer.git
   cd Automation-Smart-File-Organizer
   ```

2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```
